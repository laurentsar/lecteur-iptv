🖥️ Affichage

Affichage TV

Agrandit les textes et cibles du curseur pour une lecture à plusieurs mètres (télé, boîtier). À activer soi-même : l'app ne peut pas détecter un téléviseur de façon fiable.

Filtre lumière bleue

L'appli est déjà entièrement en thème sombre (pas de mode clair à désactiver) — ce filtre va plus loin en teintant l'écran d'ambre pour réduire la lumière bleue en soirée, plus reposant pour les yeux.

▶️ Lecture

Lecteur vidéo natif

Lecture hors WebView (Media3/ExoPlayer) : décode l'HEVC et l'audio AC3/E-AC3/DTS que le navigateur refuse, et tient mieux la charge sur une télé ou un boîtier. Décoche pour revenir au lecteur web — il reste utilisé automatiquement si le lecteur natif échoue.

💾 Sauvegarde & export (Tesla, autre appareil…)

Exporte ta configuration (playlists, favoris) sous forme d'un code chiffré, à transférer facilement vers un autre appareil — par exemple le navigateur d'une Tesla, où retaper un compte Xtream au clavier tactile est pénible.

ℹ️ Infos

⚠️ Ce que cette app fait — et ne fait pas

C'est un lecteur : il affiche et joue les flux d'une playlist M3U ou d'un compte Xtream Codes que toi tu fournis. L'app ne fournit, ne vend ni n'héberge aucune chaîne, film ou série.

🔒 Code PIN (bouquet adulte)

Protège par code les catégories dont le nom contient « adulte », « adult », « xxx » ou « 18+ ». Facultatif : tant qu'aucun code n'est défini, rien n'est masqué.

🖼️ Enrichissement TMDB (facultatif)

Complète les fiches films incomplètes en interrogeant TMDB à partir du titre. Facultatif : laisse le champ vide pour désactiver. Envoie le titre du film à TMDB (un tiers), rien d'autre.

Obtenir une clé API TMDB gratuite

Confidentialité

Tes playlists, identifiants et favoris restent uniquement sur cet appareil (stockage local). Rien n'est envoyé ailleurs qu'au serveur IPTV que tu as toi-même renseigné.
